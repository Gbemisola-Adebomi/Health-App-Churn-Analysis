# Health-App-Churn-Analysis

**Project Overview**
This project analyses customer churn within a health application using SQL and Power BI. The objective was to identify patterns in churn across subscription plans, regions, device types and workout completion levels.

**Key Questions**
What is the overall customer churn rate?
Which subscription plan has the highest churn rate?
How does churn vary by region?
How does churn vary by device type?
Does workout completion level show a relationship with churn?

**Tools Used**
PostgreSQL / SQL — data preparation and analysis
Excel/CSV — source dataset
Power BI — dashboard development and visualization

**Analysis Workflow**
Raw Data → Data Cleaning → SQL Data Modelling → SQL Analysis → Power BI → Dashboard → Insights

**Key Insight**
The analysis showed that churn patterns vary across customer segments, but the relationship between workout completion and churn was not simply linear. This highlights the importance of examining customer behaviour alongside segment size and churn rates rather than relying on assumptions.
